# OCT_Static_Software V6.0 — Schema 6.0.0

Software de adquisición y procesamiento OCT-FD.

## Requisitos

- Windows 10/11
- Python 3.12.x

Versión recomendada:

Python 3.12.10

## Instalación

Ejecutar `Instalador.bat`. El script crea `.venv` e instala las dependencias.

## Ejecución

Ejecutar `Setup.bat`. El script activa `.venv` y lanza `main.py`.

## Hardware compatible

- Ocean Optics HR4000
- Newport ESP301
